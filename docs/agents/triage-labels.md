# Triage Labels Vocabulary

Canonical triage roles and label mappings:

- `needs-triage`: Newly submitted items awaiting initial categorization and review.
- `needs-info`: Blocked on clarification or additional reproduction steps.
- `ready-for-agent`: Fully specified tasks suitable for autonomous agent execution.
- `ready-for-human`: Tasks requiring architectural sign-off, sensitive access, or user action.
- `wontfix`: Out-of-scope or rejected requests.
